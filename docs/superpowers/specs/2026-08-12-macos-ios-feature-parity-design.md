# macOS 与 iOS 用户功能对齐设计

## 目标

在不改变现有 Socket/TLS 端口、帧编号和 Android/macOS 既有行为的前提下，补齐 iOS 相比 macOS 缺失的用户可见功能，并保持 iPhone 的原生交互方式。

## 全局功能矩阵

| 页面 | macOS 用户能力 | iOS 当前状态 | 本轮处理 |
| --- | --- | --- | --- |
| 登录 | 登录、服务器配置、创建账号 | 缺创建账号 | 增加注册页与 `0x30/0x34` 仓库链路 |
| 消息列表 | 搜索、未读、置顶、好友申请、添加好友 | 已覆盖 | 不改 |
| 聊天 | 文本、表情、附件、背景、别名、复制、引用、本地删除、撤回、清空 | 缺后五项 | 增加长按菜单、引用预览、动作同步和本地缓存操作 |
| 网盘 | 目录、文件、传输、在线播放 | iOS 已覆盖或超过 | 不改 |
| 我的 | 头像、外观、传输、缓存、服务器、退出 | 已覆盖并增加通知、Face ID、Wi-Fi 设置 | 不改现有菜单 |
| 通知 | 新消息通知、点击进入会话 | 只有权限设置 | 增加通知投递和待处理路由 |
| 服务器设置 | 连接状态、测试连接 | 只有编辑和保存 | 增加独立 TLS 控制端口探测 |

## 方案选择

采用“聚焦全链路兼容”方案：iOS 完成 UI、仓库、缓存和导航，net-server 只在现有聊天发送帧中透传可选引用字段。旧客户端会忽略新增 JSON 字段，因此 Android 和 macOS 的现有连接、登录、普通消息和附件消息不受影响。

不采用两种方案：只做 UI 会造成引用和撤回无法跨设备同步；照搬 macOS 大页面会破坏 iPhone 的导航、键盘和触控体验。

## 注册

- 注册字段：账号、邮箱、密码、确认密码、可选头像。
- 账号规则与 macOS 一致：有效大陆手机号或邮箱；密码至少 6 位；邮箱必须合法；两次密码一致。
- 头像复用当前 iOS 头像处理规则，最长边 1024 像素、JPEG 质量 0.85。
- `RemoteAuthRepository.register` 发送 `userRegisterRequest(0x30)`，等待 `userResponse(0x34)`。
- 注册响应不写入 Keychain，不进入登录态；成功后关闭注册页、回填登录账号并提示用户登录。

## 消息操作

- 长按消息显示：复制、引用、本地删除；自己已发送且未撤回的服务端消息额外显示撤回；失败消息保留重试。
- 引用信息使用 `quoteMsgId`、`quoteMsgContent`、`quoteMsgSenderName` 三个可选字段，附着在现有 `0x50` JSON 中。
- net-server 将引用字段原样放入实时 `0x51` 推送；不更改帧结构、端口或 TLS。
- iOS 本地缓存保存引用字段，因此发送端和实时接收端重启后仍能展示已经缓存的引用。
- 本地删除和清空只改当前账号、当前好友的 iOS 缓存，不向服务端删除数据；重新同步服务器历史时消息会再次出现，UI 明确提示这个边界。
- 撤回使用现有 `0x59/0x5A/0x5B`，发送后立即更新本地状态，失败时恢复；收到动作推送后更新当前会话和缓存。
- 已撤回消息只显示“你撤回了一条消息”或“对方撤回了一条消息”，不能复制或再次引用。

## 通知与跳转

- 仅对对方发来的消息投递通知，自己的本地广播不通知。
- App 正在前台且用户停留在该会话时不通知；在其他页面或后台时通知。
- “显示消息预览”打开时展示消息摘要，关闭时只展示“你收到一条新消息”。
- 通知 `userInfo` 保存 `friendId`。点击后写入持久到主界面出现之前的内存路由，主界面切到“消息”Tab，好友数据就绪后进入对应会话。

## 服务器连接检测

- 测试按钮先验证当前输入的主机与四个端口，再创建独立 `NWControlConnection`。
- 只连接控制端口，复用 App 内置 CA、TLS 1.2 和主机名校验；成功后立即断开，不干扰当前登录连接。
- 页面展示测试中、成功、失败三种状态；保存仍沿用现有配置切换流程。

## 错误处理与兼容性

- 注册、撤回、连接检测都显示服务端或 TLS 的实际错误，不伪造成功。
- 引用字段可选，旧服务端或旧客户端忽略后仍按普通消息展示。
- 本轮不实现 macOS 仅有视觉动画、没有持久化语义的双击爱心。
- 不执行数据库 UPDATE、DELETE 或结构变更。

## 验证

- 每个新增仓库/视图模型行为先写失败测试，再写实现。
- 跑注册、聊天动作、缓存、通知路由和连接探测专项测试。
- 跑 iOS 全量 XCTest、普通 Simulator build、`git diff --check`。
- net-server 仅在增加引用透传时补 Java 合同测试，并用 Zulu Java 8 跑全量测试和 fat JAR 打包。
